# Робот, которому грустно

Двуязычный литературный архив и статическая читалка для GitHub Pages.

**Соавторы проекта:** [drevendev](https://github.com/drevendev) и [FreeSlave](https://github.com/FreeSlave).

**Читать:** https://drevendev.github.io/SadRobo/

**Первоисточник:** [ВКонтакте](https://vk.ru/sadrobo).

**Зеркала:** [Telegram](https://t.me/sadrobo) · [Проза.ру](https://proza.ru/avtor/sadrobo) · [Tumblr](https://therobotwhoissad.tumblr.com/).
Правила сверки: [docs/source-policy.md](docs/source-policy.md).

Чтение по порядку, полнотекстовый поиск сразу на русском и английском, каталог
по годам и темам, редакторские арки и подборки, закладки, сохранение места,
изменение размера текста и светлая/тёмная тема. Данные читателя остаются в браузере.
Сайт работает в подпапке `/SadRobo/`, без сервера, внешних шрифтов и аналитики.

Главная оформлена как металлический архив с ретрофутуристичной схемой робота.
При каждом заходе появляется случайная иллюстрация; нажатие открывает её диалог.
Кнопка «Другая иллюстрация» меняет рисунок без немедленного повтора. В читалке
переходы находятся сверху и снизу текста. Референсы и использованные рекомендации
UI/UX: [docs/design-notes.md](docs/design-notes.md).

## Что сохранено

- 244 публикации с авторского зеркала [Проза.ру](https://proza.ru/avtor/sadrobo),
  указанного в [Telegram № 9](https://t.me/sadrobo/9).
- Вся доступная лента Telegram до № 58: 55 сообщений, 50 литературных записей
  после исключения служебных сообщений, закреплений и объявления архива.
- 10 прежних английских публикаций Tumblr: девять объединены с соответствующими
  русскими записями, «Олимпийский огонь» добавлен отдельно, с английским текстом.
- Итого 295 записей в читалке, 59 уникальных изображений. Для 294 записей
  подготовлена новая английская редакция; одна запись сохранилась только в
  прежней английской редакции. «Пустота» — иллюстрация без текста.

**Полнота относительно VK пока не подтверждена.** VK вернул ограничение доступа;
браузер также заблокировал открытие по своей политике безопасности. На Проза.ру
иллюстраций к произведениям нет. В архиве могут отсутствовать VK-only тексты и
картинки. Это отражено в читалке и в `content/import-report.json`.

Даты Проза.ру — даты публикаций в зеркале, а не подтверждённые первоначальные
даты VK. При совпадении даты порядок сверяется по авторским ссылкам «Следующий
диалог». Одинаковые заголовки сами по себе не означают дубли.

Английские тексты имеют статус `ai-draft`: нужна авторская вычитка. Стиль и
адаптация описаны в [docs/translation-style.md](docs/translation-style.md).
Русский текст сохранён, убраны только форматные отступы, служебные ссылки
следующего/предыдущего диалога и хештеги рубрики Telegram. Исходные выгрузки
содержат эти элементы без очистки.

## Запустить локально

Нужен Node.js 22+; зависимостей и установки npm-пакетов нет.

```sh
npm test
npm run build
npm run dev
```

Открыть http://127.0.0.1:4317/SadRobo/. Для другого порта задайте `PORT`.

Сборка создаёт `dist/` и проверяет наличие переводов и изображений. В `dist/`
попадают читалка, локальные изображения, объединённый `archive.json` и доступные
для скачивания источники/лицензии. Ссылки на диалоги используют hash-маршруты,
поэтому работают после обновления страницы и не требуют серверных правил.

## Обновлять архив

Прямая выгрузка текстов и фотографий через VK API, без посредников и сторонних
пакетов: [docs/vk-export.md](docs/vk-export.md). Подходит **пользовательский ключ
VK API (`user`)** или сервисный ключ своего приложения (`service`);
ключ сообщества не подходит для `wall.get`. Если пользовательский ключ уже
есть, создавать приложение ради сервисного ключа не нужно.
Если готового ключа нет, в инструкции описано получение пользовательского
ключа через своё VK Mini Apps и страницу `vk-token.html`. Она запрашивает только `wall`.
Сначала `python scripts/export_vk.py --domain sadrobo --check` проверяет доступ
к началу/концу стены и одному файлу изображения без сохранения выгрузки.
После успешной проверки запустите ту же команду без `--check`.
Результат сохраняется в `.cache/vk-export/`; читалка автоматически не изменяется.
Тип ключа подтверждён официальной схемой VK, реальный доступ к SadRobo ещё
предстоит подтвердить запросом с действующим ключом. Платные, trial и внешние
сервисы выгрузки в проекте не используются.

Исходники и метаданные разделены:

| Файл | Назначение |
| --- | --- |
| `content/proza.json`, `telegram.json`, `tumblr.json` | Исходные публикации, даты, ссылки, контрольные суммы картинок |
| `content/stories.json` | Канонические русские записи со стабильными ID |
| `content/translations/` | Английская редакция, статус и заметки об адаптации |
| `content/taxonomy.json` | Темы и редакторские подборки |
| `public/images/` | Локальные картинки |
| `scripts/archive.mjs` | Объединение изданий и метаданных |

Публичные источники можно импортировать Python 3.10+, без сторонних пакетов:

```sh
python scripts/import_telegram.py
python scripts/import_proza.py
python scripts/import_tumblr.py
python scripts/prepare_content.py
```

Сетевые ответы кешируются в `.cache/`; для свежего запроса удалите конкретный
кеш нужной страницы. Сначала сделайте копию вручную отредактированного
`stories.json`: `prepare_content.py` пересобирает его из исходников. Новые
записи требуют перевода: сборка не пропускает отсутствие английской версии.
При изменении количества работ Проза.ру импорт останавливается для сверки,
вместо молчаливого принятия неполной выгрузки.

Для нового источника добавляйте точные ссылки в `sources`. Дубликаты объединяйте
по нормализованному полному тексту, сохраняя все ссылки и уникальные картинки.
Разные истории с одним заголовком оставляйте отдельными. Не угадывайте даты VK
или авторство картинок. Арки — редакторские маршруты, не заявления о каноне.

## GitHub Pages

`.github/workflows/pages.yml` запускает проверки и сборку при push в `master`,
затем публикует `dist/` в GitHub Pages. В Settings → Pages источник — GitHub
Actions. Для pull request запускается только проверка, без публикации.
