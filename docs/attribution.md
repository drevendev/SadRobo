# Авторство отдельных материалов

Dreven и FreeSlave — соавторы проекта. Часть текстов и иллюстраций прислана
другими людьми. Нельзя автоматически считать соавторов проекта авторами
каждого материала или переносить CC BY 4.0 на чужие материалы.

Реестр `content/attribution.json` редактируется отдельно от исходных выгрузок.
`import_vk.py` и другие импортёры его не изменяют. Сборка присоединяет credits
после сопоставления источников и выбора картинки. Стабильный ID позволяет
переуточнить дату/текст без потери атрибуции. SHA-256 привязывает атрибуцию к
точным байтам иллюстрации: новый вариант требует отдельного подтверждения.

| Поле реестра | Содержание |
| --- | --- |
| `schemaVersion` | `1` |
| `creators` | Словарь участников: стабильный ID → `name`, необязательный публичный `url` |
| `works` | Словарь стабильных ID произведений → `text`, необязательный `translations` со сведениями по языкам |
| `images` | Словарь SHA-256 → атрибуция конкретного файла |

Каждая запись текста, перевода или картинки содержит:

| Поле | Назначение |
| --- | --- |
| `status` | `unverified`, `partial`, `verified` |
| `creatorIds` | Массив ID из `creators`, один или несколько участников |
| `sources` | Массив публичных HTTP(S) URL, подтверждающих атрибуцию |
| `note` | Краткое основание или описание неопределённости; без личной переписки и контактов |
| `license.status` | Отдельный статус проверки прав, не связанный автоматически со статусом имени автора |
| `license.id`, `license.url` | Лицензия/разрешение и публичная ссылка на условия, когда подтверждены |

`verified` требует имени автора и хотя бы источника либо заметки с основанием.
Подтверждённая лицензия требует ID и URL. Сборка отклоняет неизвестные ID авторов
и произведений, неверные статусы, неподходящие хеши и небезопасные URL.
Наличие создателя в `creators` само по себе не назначает ему ни одной работы.
На старте реестр работ пуст: авторство восстанавливается по доказательствам,
а не по предположениям. Пустая запись означает «пока не проверено», не «без автора».

В скачиваемом архиве данные доступны в `story.credits.text`,
`story.credits.translations[language]`, `image.credits`; там ID дополнены
публичными именами/ссылками. `meta.attribution` содержит покрытие сверки.
`meta.license` теперь `per-material`; `projectContentLicense` обозначает
лицензию собственных материалов проекта, не всех файлов архива.

Отдельные авторы и проверенная лицензия выводятся в блоке публикаций диалога,
без рамок/подписей вокруг рисунка. Неизвестные сведения обозначены «уточняется».
Варианты файлов в `imageVariants` также получают отдельные credits по их хешам.

Дальнейшая работа и очередь исследований: [issue #1](https://github.com/drevendev/SadRobo/issues/1).
Новая форма предложений обязана собирать раздельные сведения для текста и картинки:
[issue #2](https://github.com/drevendev/SadRobo/issues/2).
