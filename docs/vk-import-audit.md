## Сопоставление произведений

`content/vk-mapping.json` фиксирует соответствие всех 322 постов стабильным ID
читалки. Сверялись тела и заголовки, а не только имена собеседников. При поиске
кандидатов нормализовались пунктуация, регистр и ё/е; первоисточник в архиве
сохраняется без этих преобразований. 288 соответствий имеют сходство тела
не ниже 0,85; различающиеся заголовки сверены отдельно. Два дополнительных
соответствия — визуальная «Пустота» (пост 8) и «Хештеги» (160), где хештеги
составляют сам текст и не должны удаляться как разметка.

- Пост 10 восстанавливает русский «Олимпийский огонь». Стабильный ID Tumblr
  сохранён; английский текст остаётся прежним авторским изданием.
- Посты 414, 421, 437 и 440 — отдельные монологи Джорджа Мартина. Проза.ру
  собрала их вместе в другом порядке. Прежний ID сборной записи сохранён за
  первым постом, остальным даны ID VK. Ссылка на сборник есть у всех четырёх.
  Полная редакция зеркала доступна в `mirror-stories.json` и `proza.json`.
- Пост 524 «Браш» — отдельный диалог, не «Бодипамп», несмотря на сходство.
- Разные встречи с Создателем и другие одинаковые названия не объединялись.
- Посты 1, 413, 643 — рисунки без текста; названия для каталога редакторские
  и помечены в читалке. Заголовки монологов тоже редакторские.
- Три дополнения без найденного соответствия VK: «Каноны диалогов» (`tg-006`),

Итого 325 записей вместо прежних 295, включая 30 новых отдельных записей.
Все старые ID сохранены. Для новых записей добавлены английские черновики;
перевод первого монолога соответствует теперь отдельному исходному посту.
Прежние переводы остаются черновиками: редакторские расхождения между VK и
зеркалами требуют авторской вычитки.

## Изображения и даты

Байтовые дубли используют один файл по SHA-256. Для 35 пар VK/зеркало
сопоставлена также копия того же рисунка в другом разрешении:
`content/vk-image-equivalents.json`. При сравнении проверялись отношение сторон
(отклонение < 0,02) и средняя разность яркости после приведения к 128×128
(< 5 из 255 при ненулевой детализации). Реальная разность найденных пар:
0–1,711. Эти копии не показываются дважды; исходники зеркал сохранены.
Другие варианты иллюстраций оставлены. В читалке 232 разных изображения.

Порядок первоисточника задают Unix timestamp VK и ID поста при равном времени.
`publishedAt` сохраняет точное время UTC. Календарные даты — Europe/Moscow,
с учётом исторического UTC+4 до октября 2014 года. Проверка сравнивает каждую
дату с независимой реализацией Intl в Node.js. Редакторские арки, ранее
заданные диапазонами дат зеркал, переведены на явные ID там, где это нужно.

Импорт повторяемый и полностью офлайн. Он не обращается к VK, не читает ключ,
не меняет пользовательскую выгрузку и не публикует подписанные CDN URL.
Новые неизвестные посты требуют сверки соответствий перед импортом.
