# Первоисточник и зеркала

Установлено соавтором проекта 24 октября 2026 года:

- **ВКонтакте — первоисточник:** https://vk.ru/sadrobo.
- **Telegram, Проза.ру и Tumblr — зеркала.** Tumblr сохраняет прежнюю английскую редакцию.

При восстановлении архива сначала сверяйте тексты, иллюстрации, даты и порядок
с публикациями VK. Даты и порядок зеркал нельзя выдавать за подтверждённую
хронологию первоисточника. Пока исходные записи VK не получены, сохраняйте
существующие даты зеркал с соответствующей пометкой.

Сохраняйте точную ссылку и площадку каждой полученной публикации в `sources`.
Сборка помечает записи VK как `role: primary`, остальные — `role: mirror`.
`meta.primarySource` задаёт первоисточник проекта. Не добавляйте вымышленные
URL исходных постов VK для ещё не сопоставленных записей.

Расхождения между изданиями сохраняйте для сверки; наличие первоисточника
не означает, что нужно молча удалить отличающуюся версию зеркала. Стабильные
ID уже опубликованных диалогов сохраняйте при присоединении записей VK.

Для выгрузки VK используйте прямой VK API и локальные скрипты. Платные решения,
trial и сторонние сервисы выгрузки исключены по прямому указанию пользователя.
Проверку по официальной документации отличайте от успешного реального запроса;
офлайн-тесты не подтверждают доступность стены или полноту выгрузки.
